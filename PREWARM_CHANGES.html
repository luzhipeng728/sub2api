Sub2API Prewarm Session 改动总结

分支：feat/prewarm-session-bypass  |  仓库：github.com/luzhipeng728/sub2api  |  部署：199.127.60.139:18081

🎯 核心目标

绕过 Codex 5h usage_limit，对外响应与官方 Responses API 完全一致
空 prewarm（input=[] + generate:false）→ 0 token 拿 response_id → 续发时 prompt 转 developer-role + previous_response_id 续接 → 不计 user 配额 → 绕过限额
用户请求 "你好" │ ├─ ① cache 查 prewarm_id → 命中：直接用 │ └─ 未命中：同步兜底预热（空 input + generate=false）→ 拿新 id │ ├─ ② 注入 previous_response_id（写入 wsReqBody） ├─ ③ prompt 转 developer-role（绕 user 配额统计） ├─ ④ instructions = 空格（不注入 5KB Codex prompt） │ ▼ WSv2 上游（绕过 usage_limit） │ ├─ ⑤ 成功：滚动更新（新 id 写回 store） ├─ ⑥ 失败(404)：失效自愈（清 store + recover 重新预热） │ ▼ 响应清洗（隐藏内部机制） │ ├─ previous_response_id → null ├─ instructions → null └─ codex.rate_limits → 过滤 │ ▼ 对外响应（与官方 API 一致）
